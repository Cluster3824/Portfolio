RESUME PDF SETUP INSTRUCTIONS
=============================

To enable the resume download functionality:

1. Create your resume as a PDF file
2. Name it "resume.pdf" 
3. Place it in the "public" folder of your React project
4. The download button will automatically work

File path should be:
public/resume.pdf

The resume component will automatically:
- Display your resume information on the webpage
- Allow visitors to download the PDF version
- Show a professional formatted resume layout

Note: You can also rename the file in the Resume.js component by changing the 'href' and 'download' attributes in the handleDownload function.
